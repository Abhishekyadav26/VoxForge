# C5: plan/trace duplication + status legibility

## Problem
Workflow rows restate graph nodes; diagram stays neutral on trigger; double "Worked for"; toolbar overlaps s2 (S-2, S-3, S-4). Criteria: state once, diagram reflects status, single duration, no overlap.

## Options considered
| Option | Idea | Scores |
|--------|------|--------|
| A Minimal | dedupe + status tint + padding | 50 / 46 / 50 = 146 |
| B Restructure | single timeline, graph as toggle | 52 / 54 / 32 = 138 |
| C Convention | CI-check rows | 50 / 50 / 40 = 140 |

## Decision
**A**: hide workflow tool rows after graph reveal (keep reasoning), tint notify node by `triggered`, single "Worked for" label, `pl-8` on graph container to clear the toolbar.

## Why this is the best
- Against B/C: both rework the animation components users already read successfully — the trace prose tested well ("s1.price < 150? YES" is plain language). A removes the duplication without redesigning what works.
- Norms: C2, C3, H4, H6. Costs: three small file touches; rules out nothing.

3. `AgentRunView.tsx` — status pill header.
