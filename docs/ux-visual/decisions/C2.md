# C2: raw engine internals as the UI

## Problem
Detail page's main content is raw AgentSpec JSON; runs/meta use ISO timestamps + machine ids; 454px scroll. Findings A-1, A-2, A-3, A-6. Criteria: human summary first, JSON collapsed, localized dates, no scroll for 1-run agent.

## Options considered
| Option | Idea | Weighted score |
|--------|------|----------------|
| A Minimal | details-collapse + date format | Usab 42 / Vis 38 / Eng 48 = 128 |
| B Restructure | SpecSummary + RunRow components | Usab 52 / Vis 52 / Eng 40 = 144 |
| C Convention | monitoring-tool plain language | Usab 54 / Vis 50 / Eng 34 = 138 |

## Decision
**B with C's copy**: `SpecSummary` (trigger pill + plain-language condition sentences + action line) and `RunRow` (relative time + triggered pill + expandable trace); copy in C's plain words ("Alert when SOL drops below $150 · checked every 60s"); raw JSON in a collapsed "Developer" block. List cards: name + status pill + relative last-run, no ids.

## Why this is the best
- Against A: collapsing JSON still shows ISO soup in the list and runs; B fixes all three surfaces.
- Against C: C's renderer must handle every block type up front; B's structured summary reuses existing summarizers with C's wording.
- Norms: C1, C2, D5, L1, P1. Costs: two new components; rules out nothing (JSON stays one click away).

## Implementation plan
1. `components/SpecSummary.tsx` (new) — trigger pill, step rows, action line.
2. `components/RunRow.tsx` (new) — relative time, pill, expandable trace.
3. `app/agents/[id]/page.tsx` — compose summary + runs; JSON into `<details>`.
4. `app/agents/page.tsx` — card meta humanized.

## Test plan
Assert: no ISO string in default view; `<details>` closed by default; 1-run detail scrollY=0 at 1440×900; relative-time format unit test.
