# C6: mobile header + composer density

## Problem
390px: brand wraps, Sign out wraps, chips 24–26px on cramped rows (H-4, S-6). Criteria: single-line header, ≥44px composer rows, no collisions.

## Options considered
| Option | Idea | Scores |
|--------|------|--------|
| A Minimal | responsive Tailwind rules | 50 / 44 / 52 = 146 |
| B Restructure | avatar menu + bottom sheet | 48 / 50 / 34 = 132 |
| C Convention | compressed GitHub-style | 44 / 44 / 42 = 130 |

## Decision
**A**: `sm:`-gated short brand ("VoxForge" + hide "Voice-to-Agent" span), tighter nav gaps, chips `py-2.5` in a 2×2 grid on mobile with Send full-row below; header gets `whitespace-nowrap` + smaller gaps.

## Why this is the best
- Against B: a menu hides Studio/Agents behind a tap for a 2-link nav — unjustified.
- Against C: "+"-menu hides the voice vocabulary, same objection as C4-C.
- Norms: L6, I4, H5. Costs: classes only; rules out nothing.

## Implementation plan
1. `app/layout.tsx` — responsive brand/nav.
2. `app/studio/page.tsx` — composer grid + chip sizing.

## Test plan
390px: brand single line, no wrap on Sign out, chips ≥44px rows, no horizontal scroll (audit).
